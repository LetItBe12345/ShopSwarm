# M0.1 确定环境与集成接口：已确认决策

日期：2026-09-23。对应任务：[M0.1 确定环境与集成接口](../TODO/in-progress/M0.1-确定环境与集成接口.md)。

## 已确认决策

1. 首个开发和验证平台定为 Ubuntu 24.04 x86_64。首版只承诺该环境中实际验证通过的能力，其他平台留到后续实测。
2. Node.js 基线定为 22.23.2，满足当前 DSH 副本声明的 `^22.19.0 || >=24.0.0`。包管理器使用 DSH 当前声明的 pnpm 11.7.0，通过 Corepack 固定版本；本机现有 pnpm 9.15.9 不作为项目基线。
3. DSH 集成沿用外部 Bundle、Host Plugin 和 Skill，不修改 DSH 源码。工具使用 `defineTool` 和 `ctx.tools.register` 注册；调用归属、调用编号和取消信号分别从执行上下文的 `exec.agent`、`exec.callId` 和 `exec.signal` 获取，不接受模型传入这些值。
4. 用户入口接受自然语言购物查询。DSH 根据查询拆分任务，ShopSwarm 在内部把自然语言目标整理成站点、商品约束、完成条件和预算；用户不需要按内部数据结构填写请求。
5. 消费级 NVMe 固态硬盘只是首批测试品类，不是运行时品类白名单。首批测试至少核对品牌、精确型号和容量；颜色等不适用品类的字段不作为该测试品类的必填条件。其他品类可以执行，但在完成对应验证前不能写成已支持能力。
6. 京东和天猫只是首批测试及支持声明使用的候选站点，不是运行时站点白名单。首批测试中，京东只采集京东自营报价，天猫只采集品牌官方旗舰店报价。其他站点可以尝试执行，但应明确标为未验证；卖家身份必须作为报价证据的一部分，不能只按页面标题推断。
7. 真实站点验证允许使用复制出的专用登录 Profile。程序只操作副本，不修改原 Profile；首版只做查询和取证，不购买、不下单、不支付、不领券，也不修改账户。
8. 首版允许调用 TypeSafe 托管 Jev API。只有在任务参数没有提供所需输入文本时，才允许调用单独的 OpenAI 兼容文本模型。密钥只从环境变量读取，真实站点和付费 API 测试必须显式启用。

## 仍需验证

- 核对并实测 DSH 工具结构化输出、Agent 作用域、取消传播、注册释放和插件卸载行为；源码阅读结果不能代替运行验证。
- 固定 ShopSwarm 的直接依赖版本和锁文件，并验证 pnpm 11.7.0 在本机通过 Corepack 可复现使用。
- 验证 agent-browser 对复制 Profile 的启动、会话隔离、后台运行、焦点行为和清理。未经验证前，不承诺登录态一定可复用。
- 验证京东和天猫在所选环境中的页面可访问性、验证码、价格可见性和卖家证据。站点之一无法稳定验证时，另行确认替代站点，不在本决策中预设备用站点。
- 用脱敏测试请求核对 TypeSafe Jev API 的实际请求和响应格式、超时、取消、费用记录及错误返回。现有文档示例不视为 ShopSwarm 已对接的 HTTP 契约。
