# M0.3 阶段验收：已确认决策

日期：2026-09-23。对应任务：[M0.3 阶段验收](../TODO/done/M0.3-阶段验收.md)。

## 已确认决策

1. M0.3 使用真实 DeepSeek API 验证自然语言 Agent 调用，不以脚本化模型代替。当前使用 DSH 默认的 `deepseek-official/deepseek-flash`。
2. DeepSeek 使用官方默认地址 `https://api.deepseek.com`。API Key 只放在 Git 忽略的本地 `.env`；`DEEPSEEK_BASE_URL` 不写入 `.env`。
3. 验收使用系统临时目录中的独立 `DSH_HOME` 和 `headless` profile，不读取或修改用户现有 DSH 配置。
4. ShopSwarm 先构建为本地 tarball，再通过 DSH plugin 命令安装。profile 只明确允许 agent-browser 的安装脚本，不依赖全局 DSH、agent-browser 或参考仓库路径。
5. 正常、失败和取消场景均使用本地固定页面。真实站点和登录 Profile 不属于 M0 验收。
6. ShopSwarm 的一次性浏览器诊断使用单独的 agent-browser socket 目录。资源归属仍由 Agent 身份和工具调用编号派生。
7. 为处理宿主在中断后强制退出的情况，每个诊断会话创建一个会话专属清理看门进程。它只在核对会话 PID、会话名和 socket 目录一致后释放该进程，不使用全局关闭。
8. 阶段验收脚本必须完成移除验证，并删除临时 profile、tarball 和本地页面；输出不得包含密钥、Cookie、Profile 或完整模型记录。

## 后续边界

- M2 验证 Jev 动作循环、真实站点和结构化报价。
- M3 才实现购物任务的多 Agent 分发；本阶段的自然语言调用只证明 DSH Agent 可以选择并调用 ShopSwarm 工具。
