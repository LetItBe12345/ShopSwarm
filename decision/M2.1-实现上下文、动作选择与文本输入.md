# M2.1 实现上下文、动作选择与文本输入：已确认决策

日期：2026-09-23。对应任务：[M2.1 实现上下文、动作选择与文本输入](../TODO/done/M2.1-实现上下文、动作选择与文本输入.md)。

## 已确认选择

1. M2 暂不增加任务级总时长、动作次数或连续失败次数预算。M1.2 的单条浏览器命令超时仍然有效。roadmap 的 M2.4.4 以及 M2.2、M2.4 任务文件中原有的任务级预算验收表述按此修正。
2. 网页 `TYPE_TEXT` 所需内容不是要求用户另填一份文本。任务中有明确值时直接使用；没有明确值时使用现有 DeepSeek 官方 API 生成。当前 DSH 默认模型为 `deepseek-official/deepseek-flash`，文本辅助使用同一模型的 API 名 `deepseek-flash`。文本模型不能凭空补出任务缺少的必要事实。
3. 首版允许把登录后页面的内容发给 TypeSafe 托管 Jev API，即使页面中有地址、手机号等个人信息。页面快照属于 Jev 动作判断的输入；Cookie 和 API 密钥不是页面快照内容。

## 实现口径与验证边界

- Jev 请求使用 `state` 和 `questions`，以本地参考仓库及 TypeSafe 官方 SDK 的接口为依据。当前没有 `TYPESAFE_API_KEY`，本任务用可控响应验证请求形状、选项约束和错误返回；真实 TypeSafe 服务响应仍需在配置密钥后实测，不能写成已通过。
- DeepSeek 文本辅助只在任务没有非空明确文本时调用。返回的 Token 用量与耗时单独记录；响应未提供实际金额时费用标为未知。
- 完整动作循环、独立完成检查和真实购物站点验证分别属于 M2.2、M2.3。
