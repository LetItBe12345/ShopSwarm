# M2.3 任务泛化与固定测试用例：已确认决策

日期：2026-09-23。对应任务：[M2.3](../TODO/done/M2.3-验证单站任务并建立性能基线.md)。本文件取代 [M0.1](M0.1-确定环境与集成接口.md) 里把 NVMe、京东和天猫写成首批产品范围的部分。M0.1 的运行环境、DSH 接口和密钥规则仍然有效。

1. 运行范围按调用方给出的任务决定，不写死某一个模型或某一种购物场景。同一任务要能换模型、换场景、换来源。来源可以是购物页面，也可以是某个模型的官方 API、官方 Coding Plan 或第三方 API 提供方。
2. GLM-5.3 只是一套固定测试用例，用来检查价格抽取、相邻模型不要并条、按量单价和套餐额度分开、未知额度保持未知。换一个模型标识或换一个购物场景时，沿用同一套输入、评分和证据规则。测试用例里的金额不是项目已验证的市场价格。
3. 京东、天猫、淘宝不再作为默认验收站点。这些页面实测无法稳定打开，不再重试，也不再加专用处理。其他购物场景可以提交；没有按同一规则复核过的，标为未验证，不能写成支持范围。
4. 比较时固定任务内容、模型标识、参数、输出限制和评分规则。提供方或页面实际给出的模型版本、规格或计费方式不一致时单独标记，不能把差异写成单纯的价格或线路差别。
5. 费用按任务里真正出现的口径记录。Token 任务分开记输入、输出、缓存单价，以及套餐价格、周期、额度和高峰规则。购物任务分开记标价、已确认费用和未知费用。缺字段、缺来源或没有核对日期时标为未知。第三方转述必须带回原始来源和日期。
6. 性价比同时看质量或任务是否完成、成功与失败、延迟、调用次数、原始 Token 用量和可核实费用。单价、套餐标价、Token 数或少量样本耗时不能单独作为结论。
7. 浏览器用于打开公开页面并保留摘录、链接和采集时间。不破解验证码，不购买，不支付。DSH 并行汇总仍属于 M3。
