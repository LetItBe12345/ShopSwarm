# M1.1 实现浏览器执行适配层：已确认决策

日期：2026-09-23。对应任务：[M1.1 实现浏览器执行适配层](../TODO/in-progress/M1.1-实现浏览器执行适配层.md)。

## 已确认决策

1. 点击、填写和选择等元素动作只接受最近一次有效页面快照中的元素引用。公开适配层不接受 CSS 或 XPath 选择器，也不在引用失败后降级到选择器。引用失效时重新获取快照，由上层根据新的有效元素集合重新选择目标。
2. 默认页面观察使用紧凑的完整无障碍树，同时解析并保留结构化元素引用。不能只保留交互元素，因为价格、规格、卖家等购物信息可能是普通文本。M1.1 不实现增量快照及其合并状态。
3. 命令已经发出但无法确认是否生效时，动作结果记为 `uncertain`，不得自动重试。只要任务尚未取消，适配层随后自动获取一次新页面快照，并将观察结果随动作结果返回；任务已经取消时停止观察并进入资源清理。

## 由现有规划确定的实现边界

- 同一任务保持同一个 agent-browser 会话标识；资源归属不能由模型参数指定。
- 使用参数数组调用 agent-browser CLI 并解析 JSON 输出，不拼接 shell 命令。
- 本任务只封装打开、快照、点击、填写、选择、按键、滚动、等待、后退和关闭。条件等待、Profile 和后台会话验证属于 M1.2。M1.2 已确认不设任务级执行预算。
- 页面导航或引用失效后获取新快照。引用必须绑定到页面状态版本，旧页面状态中的引用不能继续执行。

## 尚待实际验证

- agent-browser 0.38.1 各命令的 JSON 成功及错误结构，以本地固定页面实测为准。
- 哪些 CLI 退出情况表示动作确定失败，哪些表示命令可能已送达但响应丢失，需要通过可控的超时、进程中断和失效引用测试确定。
- 自动观察仍可能失败；此时保留 `uncertain` 动作结果，并附观察失败原因，不能改写为动作失败或成功。
