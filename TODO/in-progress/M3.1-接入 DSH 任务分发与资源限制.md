## 范围

让 DSH Lead Agent 把同一个 Coding Plan 比较任务分发到多个来源。ShopSwarm 不自建 Agent 调度器，只管理本插件拥有的浏览器、HTTP 请求和并发资源。

## 执行清单

- [ ] M3.1.1 Lead Agent 将同一模型、计费需求和字段要求交给至少两个来源的 Subagent。
- [ ] M3.1.2 各来源使用统一任务条件和结果结构；来源差异只体现在页面、提供方和实际证据。
- [ ] M3.1.3 使用 DSH 现有 Subagent / 并行能力。ShopSwarm 只管理浏览器或请求的资源上限与归属。
- [ ] M3.1.4 并发上限可配置；超过上限的来源等待资源，不随来源数量无限启动浏览器。
- [ ] M3.1.5 首批默认用公开 Coding Plan / 中转套餐来源验证，不以商城页面作为默认用例。

## 验证方式

同一个 Coding Plan 任务先逐个执行，再并行执行至少两个来源。核对输入一致、结果归属、资源上限和取消等待行为。
