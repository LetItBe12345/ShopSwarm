# M3.3 阶段验收

状态：in-progress（未开始）。建立日期：2026-09-23。

- 前置条件：M3.1、M3.2。
- 当前范围：[通用购物任务决策](../../decision/产品范围-通用购物任务.md)。

## 范围

验收 DSH 对同一自然语言购物任务的多来源并行执行、资源限制、取消和局部失败。M3.1 的 Coding Plan 运行保留为历史基线；M3.3 必须再验证至少一个非 Coding Plan 任务。

## 执行清单

- [ ] M3.3.1 同一购物任务的至少两个来源在并行与逐个执行时使用相同硬约束和待核对字段，结果可分别追溯。
- [ ] M3.3.2 超出资源上限的任务等待，不突破限制。
- [ ] M3.3.3 取消整体任务后子任务和所属资源停止；单来源失败时其他来源仍可结束。
- [ ] M3.3.4 并行和顺序版本使用同一 Verifier，不因并行切换判断标准。
- [ ] M3.3.5 记录总耗时、成功/失败/阻塞数和峰值内存，判断并发带来的实际收益。
- [ ] M3.3.6 至少一个非 Coding Plan 的公开购物任务完成多来源分发，证明调度和归属层没有绑定模型/套餐语义。

## 验证方式

同一任务交替运行顺序与并行版本，检查结果归属、资源上限、取消释放和指标。默认选公开、无需登录、风控较低的来源；遇到验证码或频控记录后更换来源，不把绕过风控作为验收步骤。

- [ ] 同步 roadmap 和 TODO 索引。
- [ ] 完成后移入 `TODO/done/`。
