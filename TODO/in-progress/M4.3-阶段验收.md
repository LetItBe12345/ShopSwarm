## 范围

验收通用购物任务模型、可比性判断、确定性计算和多来源报告。Coding Plan 是复杂领域样例之一，不能作为唯一验收域。

## 执行清单

- [ ] M4.3.1 不同目标、型号/变体、套餐、价格语义和适用条件不会被误合并。
- [ ] M4.3.2 不同单位或时间窗口在没有明确换算依据时不会被压成统一数字；包括 Coding Plan 的 Token/request/credit，也包括实体商品的不同包装、容量或数量单位。
- [ ] M4.3.3 必要价格、条件、属性、费用或币种未知时，不输出伪确定综合费用或最低价。
- [ ] M4.3.4 金额、单位换算和 comparability 有独立确定性测试，模型不承担算术与排序。
- [ ] M4.3.5 真实 E2E 至少覆盖数字服务 / Coding Plan、消费电子和另一类实体商品或消费品；每个自然语言任务至少核对两个公开来源，来源失败时保留失败原因。
- [ ] M4.3.6 每条参与排序的价格、属性和条件都能回溯到来源与采集时间。
- [ ] M4.3.7 独立重开验证能区分“同一对象与价格语义下金额变化”和“对象、变体或价格条件发生变化”。

## 验证方式

运行通用数据模型、comparability、金额/单位和报告测试；再按真实 E2E 矩阵复核多领域、多来源报告。默认选择无需登录且风控较低的公开来源，不以绕过验证码或频控完成验收。
