# M4.2 建立 Coding Plan 证据关联与比较报告

状态：in-progress（未开始）。建立日期：2026-09-23。

- 前置条件：M4.1；复用 M2/M3 的来源与执行结果。
- 产品规则：[Coding Plan 比价规则](../../DOC/Coding%20Plan%20比价规则.md)。

## 范围

把多个来源的 PlanOffer 整理成可追溯的比较结果。报告必须区分“可比”“条件可比”“信息不足”“不匹配”“来源失败”，而不是为了输出一个最低价强行归一化所有套餐。

## 执行清单

- [ ] M4.2.1 每个价格、额度、倍率、模型支持和限制字段都关联具体证据、来源和采集时间。
- [ ] M4.2.2 报告同时显示原始计费口径和确定性归一化结果；无法安全换算时只显示原始值。
- [ ] M4.2.3 明确显示 priceType、billingPeriod、eligibility、quota metric/window/resetRule，避免首购价、续费价和不同额度窗口被误读成同一口径。
- [ ] M4.2.4 报告将 unknown 与 0 分开；缺失缓存价、额度、倍率或限制不能被渲染成免费、无限或无条件。
- [ ] M4.2.5 只排序通过 comparability 检查的条目。不可比项单独展示原因。
- [ ] M4.2.6 输出本次实际查询到的提供方和失败来源，不宣称覆盖整个市场。

## 验证方式

使用至少两份本地样例和 M3 的真实来源记录生成报告。逐字段反查 provider、plan、model、billing、price、quota、source 和 observedAt。

## 完成条件

- [ ] 所有参与排序的字段都能追溯到证据。
- [ ] 不可比和 unknown 项不会影响确定性排序。
- [ ] 同步 roadmap、接口文档和 TODO 索引。
- [ ] 完成后移入 `TODO/done/`。
