# M4.2 建立通用证据关联与比较报告

状态：in-progress（未开始）。建立日期：2026-09-23。

- 前置条件：M4.1；复用 M2/M3 的来源与执行结果。
- 当前范围：[通用购物任务决策](../../decision/产品范围-通用购物任务.md)。

## 范围

把不同来源的通用报价 / 候选结果整理成可追溯比较结果。报告必须区分“可比”“条件可比”“信息不足”“不匹配”“来源失败”，而不是为了输出一个最低价强行归一化不同商品、套餐或价格条件。

## 执行清单

- [ ] M4.2.1 每个参与判断的身份、属性、价格、条件、费用和领域扩展字段都关联具体证据、来源和采集时间。
- [ ] M4.2.2 报告同时显示原始口径和有依据的确定性归一化结果；无法安全换算时只显示原始值。
- [ ] M4.2.3 明确展示会影响可比性的商品/服务身份、变体、价格类型、适用条件和领域属性，避免跨对象或跨条件误比较。
- [ ] M4.2.4 unknown 与 0 分开；缺失价格、运费、额度、倍率、库存或限制不能被渲染成免费、无限或无条件。
- [ ] M4.2.5 只排序通过 comparability 检查的条目。不可比项单独展示原因。
- [ ] M4.2.6 输出本次实际查询到的来源和失败来源，不宣称覆盖整个市场、所有平台或所有卖家。

## 验证方式

使用至少三类本地样例和 M3/Q.1 的真实来源记录生成报告。逐字段反查目标身份、属性、seller/provider、price、conditions、source 和 observedAt；Coding Plan 额外反查 billing、quota 等扩展字段。

- [ ] 不可比和 unknown 项不会影响确定性排序。
- [ ] 同一报告框架能处理 Coding Plan 和至少两类非 Coding Plan 商品。
- [ ] 同步 roadmap、接口文档和 TODO 索引。
