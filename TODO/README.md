## 当前执行方向

ShopSwarm 的当前产品范围是**通用自然语言购物与价格研究**。用户描述想买什么和约束，Lead Agent 将任务拆成多个公开来源的子任务；商品类别、平台和来源不在产品层写死。

Coding Plan、LLM API 套餐和第三方中转套餐是已经验证过的一组测试域。M2.4/M3.1—M3.3 的相关记录保留为历史结果，但不再定义 M4—M5 的唯一验收方向。

后续任务统一遵守 [当前产品范围决策](../decision/产品范围-通用购物任务.md) 和 [真实购物任务与测试策略](../DOC/真实购物任务与测试策略.md)：

- 原始入口是自然语言购物意图；
- 硬约束、偏好、来源和待核对字段从任务派生，不绑定 Coding Plan；
- Jev 只做受约束的浏览器动作选择；
- 页面没有公开的字段保持 unknown；
- 金额计算、单位换算、可比性和排序使用确定性代码；
- Coding Plan 的特殊价格/额度语义作为领域扩展和 fixture；
- 真实 E2E 覆盖多个购物域和多个来源；
- 登录墙、验证码和频控保留为结果，默认改用低摩擦公开来源，不通过绕过风控满足验收。

已有 M1/M2 的 `ShoppingTask`、`Offer`、`model + specs + seller` 属于兼容接口。M4 负责把任务、报价、证据和比较契约真正通用化。
