## 状态与维护

- `in-progress/`：所有未完成任务，包括未开始、处理中和受阻任务；正文注明具体情况与原因。
- `done/`：动作与完成条件全部满足，并附验证记录后移入。目前没有已完成任务，`.gitkeep` 仅保留空目录。
- 完成子项时同步 roadmap 同编号条目；实现及阶段验收全部通过才能勾选阶段。
- 移动文件时保留编号，更新本索引及 roadmap 链接；新增任务追加编号，不重排。
- DOC 保存产品规则与接口约定，TODO 保存动作与验证记录。确认的选择按需写入同编号 decision 文件；待确认项不写成决策。
