## 执行与验证记录

2026-09-23 在 Ubuntu 24.04.4 LTS、Linux 6.8 x86_64 上完成。使用 Node.js 24.21.0、pnpm 11.7.0、DSH 0.1.7-alpha.2、Cordis 4.0.4、agent-browser 0.38.1 和 Google Chrome 153.0.8010.52。

- M0.2.1：建立 [package.json](../../package.json)、[Bundle patch](../../cordis.patch.yml) 和 [Host Plugin](../../src/index.ts)。`shopswarm_diagnose` 已通过 DSH ToolRuntime 注册和调用。
- M0.2.2：`.node-version`、包清单、pnpm 锁文件和 `pnpm-workspace.yaml` 固定项目环境；`pnpm check` 包含类型检查、单元测试和构建。
- M0.2.3：[浏览器冒烟脚本](../../scripts/smoke-browser.ts) 启动本地固定页面，工具依次打开页面、读取快照和关闭独立会话。快照包含 `SHOPSWARM_BROWSER_SMOKE_OK`，结束后的会话列表为空。
- M0.2.4：[安装与运行](../../DOC/安装与运行.md) 和 [兼容性记录](../../DOC/兼容性与支持范围.md#m02-最小插件与浏览器连通验证) 记录 XDG 配置、状态和缓存目录。测试没有使用参考仓库作为运行目录，没有读取凭据、Cookie 或用户 Profile。

执行命令：

```bash
pnpm install
pnpm check
pnpm smoke:browser
pnpm exec agent-browser session list --json
pnpm pack --pack-destination <临时目录>
```

结果：4 项单元测试、类型检查和构建通过；浏览器诊断返回 `status: ok` 与 `markerFound: true`；会话列表返回空数组；包清单不含参考仓库或运行数据。已确认选择见 [M0.2 决策](../../decision/M0.2-建立最小插件与浏览器连通流程.md)。

独立 DSH profile 的安装、自然语言 Agent 调用、失败/取消/卸载清理仍属于 M0.3，本任务不将这些内容写成已验证能力。
