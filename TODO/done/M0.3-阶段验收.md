- M0.3.2：正常、标记不匹配失败和 SIGINT 取消场景均完成资源检查。ShopSwarm 任务会话消失，预先创建的外部会话保持存活；最后只主动关闭该外部测试会话。
- M0.3.3：[安装与运行](../../DOC/安装与运行.md#m0-阶段验收) 记录 `pnpm acceptance:m0` 的前置条件和动作。脚本从全新临时目录执行安装、运行、移除和临时文件删除。
- M0.3.4：DSH CLI 是锁定的项目开发依赖；ShopSwarm 以 tarball 安装。没有修改 `可参考项目/`，没有使用全局 DSH 或 agent-browser。外部参考提交仍沿用 M0.1 记录。

最终命令：

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm acceptance:m0
```

最终输出的 7 项布尔结果均为 `true`：profile 安装、自然语言工具调用、正常清理、失败清理、取消清理、外部会话保留和移除全部通过。详细环境、失败修复和限制见 [兼容性记录](../../DOC/兼容性与支持范围.md#m03-独立-profile-阶段验收)，已确认选择见 [M0.3 决策](../../decision/M0.3-阶段验收.md)。

执行中修复了三项问题：profile 未允许 agent-browser 安装脚本、DSH 拒绝从 `.env` 读取网络入口、宿主 SIGINT 的 5 秒退出上限短于浏览器操作。最终方案均已重新执行并通过。
