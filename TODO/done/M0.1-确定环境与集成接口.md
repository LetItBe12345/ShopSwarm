## 已确认结果

- 首个验证平台：Ubuntu 24.04 x86_64。
- 版本基线：Node.js 24.21.0、pnpm 11.7.0、DSH 0.1.7-alpha.2、agent-browser 0.38.1。
- 集成方式：DSH 外部 Bundle、Host Plugin 和 Skill，不修改 DSH 源码。
- DSH 工具：`defineTool` + `ctx.tools.register`；成功值按 `output.schema` 校验，再由 `output.render` 生成模型可见内容。
- 调用归属：`exec.agent.id` 标识 Agent，`exec.callId` 标识调用，`exec.rootCallId` 关联根调用；不接受模型提供身份。
- 取消：观察并传递 `exec.signal`；区分调用前取消和调用中取消。
- 释放：工具注册由 Cordis effect 自动撤销；外部资源同时使用调用级 `finally` 和插件级 `ctx.effect()` 释放。
- 用户入口：自然语言购物查询。NVMe 固态硬盘、京东自营和天猫品牌官方旗舰店只是首批测试边界，不是运行时白名单。
- 登录：允许使用复制出的专用 Profile，只做查询和取证；不修改原 Profile 或账户，不购买。
