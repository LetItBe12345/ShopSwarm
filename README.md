# ShopSwarm

ShopSwarm 是一个面向**自然语言购物与价格研究**的多 Agent 项目。用户直接描述“想买什么、有什么约束、希望比较什么”，Lead Agent 再把任务拆成多个公开来源的研究子任务。商品可以是实体商品，也可以是数字服务或套餐；平台和来源不在产品层写死。

Coding Plan、LLM API 套餐和第三方中转套餐是当前已经使用过的一组测试域，GLM-5.3 只是其中的固定测试用例。它们用于覆盖复杂价格语义，不代表 ShopSwarm 只做 Coding Plan。

底层架构保持领域无关。DSH 负责高层任务与 Subagent 调度，Jev 只从当前有效动作集合中选择下一步浏览器动作，ShopSwarm 负责上下文、目标校验、执行、证据检查和后续比较，agent-browser 负责实际浏览器操作。金额计算、单位换算、可比性和排序不交给模型。

## 首版范围

首版读取、核对并比较公开可访问的信息，不自动购买、充值或支付。核心要求是：

- 用户以自然语言给出购物目标、硬约束和偏好；
- 同一任务可以分发到多个公开来源；
- 每个来源独立保留目标身份、属性、卖家或提供方、价格、条件、来源和采集时间；
- 未观察到的字段保持 unknown，不用 0、免费、无限或常识补齐；
- 只有满足同一比较条件的条目才进入确定性排序；
- 结果必须能回溯到页面或接口证据。

真实 E2E 优先选择公开可读、无需登录、风控较低、能够独立重开的页面。登录墙、验证码、频控或明显反自动化限制按失败/阻塞记录，然后换其他测试来源。选择低摩擦来源是为了稳定验收，不把绕过站点安全措施当作能力。

首版测试至少覆盖数字服务 / Coding Plan、消费电子、其他实体商品或消费品三类自然语言任务，并跨多个来源。详细规则见 [真实购物任务与测试策略](DOC/真实购物任务与测试策略.md)。
