# ShopSwarm

ShopSwarm 按调用方给出的任务，比较不同来源上的结果和代价。任务可以是购物场景，也可以是某个模型的 Coding Plan 或 Token 价格。模型标识和场景都是输入。M0 和 M1 已通过，M2 的动作循环和本地页面复核已实现。

首版通过 DeepSeek Harness 外部 Bundle、Host Plugin 和 Skill 接入。比较结果要带来源、币种、采集时间和未知项，不把未核对的标价写成已确认费用。GLM-5.3 只出现在固定测试用例里。

## 首版范围

首版保持任务输入通用，并用少量固定用例验收。自动购买、支付、验证码破解、多浏览器后端和独立 UI 不在首版范围内。具体价格以执行时核对的资料为准。
