# ShopSwarm

ShopSwarm 是一个面向**价格与套餐研究**的多 Agent 比较项目。首个真实领域确定为 **Coding Plan、LLM API 套餐和第三方中转套餐**：从多个来源读取价格、额度、计费周期、模型支持范围和条件规则，保留证据，再用确定性代码判断哪些条目可以比较。

底层架构仍保持通用。DSH 负责高层任务与 Subagent 调度，Jev 只从当前有效动作集合中选择下一步浏览器动作，ShopSwarm 负责上下文、目标校验、执行和证据检查，agent-browser 负责实际浏览器操作。金额计算、额度换算和排序不交给模型。

## 当前状态

- M0、M1 已完成并验收。
- M2.1 已完成有限上下文、动态动作空间、Jev 选择与文本输入。
- M2.2 已完成单站动作循环、独立完成检查、重开页面复核，以及登录、验证码、超时和无进展的结构化返回。
- M2.3 已完成固定用例与本地 provider benchmark。GLM-5.3 只是测试样例；模拟来源不能代表真实市场价格。
- 当前下一项是 M2.4。M2.4 起，真实验收主线切换到 Coding Plan / 中转套餐公开页面。
- M3 将验证同一 Coding Plan 任务的多来源并行执行。
- M4 将新增面向 Coding Plan 的数据契约、归一化、可比性判断和比较报告。

当前代码仍保留 `ShoppingTaskContext`、`ShoppingTask`、`Offer`、`src/shopping/` 等 M1/M2 历史命名。这些接口已经实现；计划中的 `PlanOffer` 和字段驱动完成条件尚未实现，不能把文档草案写成现有能力。

## 首版范围

首版优先核对公开可读的官方价格页、Coding Plan 页面和第三方中转站套餐页。核心关注：

- 提供方、套餐、模型或模型集合；
- 按量、包月、包年、积分等计费方式；
- 常规价、促销价、首购价、续费价等价格语义；
- Token、request、credit 等额度单位及其窗口、重置规则；
- 模型倍率、峰谷倍率、缓存价格；
- API / Coding 工具兼容性与明确限制；
- 来源、采集时间和逐字段证据。

未知字段保持 unknown。缺失额度不表示无限，缺失缓存价不表示免费。不同计费方式、不同价格语义和不同币种默认不强行合并排序。

首版只读取和比较信息，不购买、不充值、不支付，也不以绕过验证码或站点风控作为验收条件。京东、天猫、淘宝不再作为默认真实验收站。
