# 安装与运行

本页记录 M0.2 的开发安装和诊断方式。自然语言购物任务、真实站点和登录 Profile 尚未接入。

## 版本

- Node.js：24.21.0
- pnpm：11.7.0
- DSH：0.1.7-alpha.2
- agent-browser：0.38.1

仓库通过 `.node-version` 和 `package.json` 记录 Node.js 与 pnpm 版本。进入仓库后运行：

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm smoke:browser
```

`pnpm check` 执行类型检查、单元测试和构建。`pnpm smoke:browser` 启动仅监听 `127.0.0.1` 的临时页面，通过 DSH ToolRuntime 调用 `shopswarm_diagnose`，依次打开页面、读取快照和关闭独立会话。

## Bundle 和 Host Plugin

`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`。补丁向已有 DSH profile 加入 `shopswarm` Host Plugin。插件入口是 `dist/index.js`，注册工具 `shopswarm_diagnose`。

M0.2 只验证了源码环境中的插件加载和工具调用。把本包安装进独立 DSH profile、从自然语言 Agent 调用工具以及卸载流程属于 M0.3。

## 用户数据位置

ShopSwarm 遵循 XDG 基础目录。未设置对应环境变量时使用：

- 配置：`~/.config/shopswarm`
- 状态和脱敏运行记录：`~/.local/state/shopswarm`
- 可删除缓存：`~/.cache/shopswarm`

测试和运行不得把数据写入 `可参考项目/`。浏览器连通测试使用临时、无登录的 agent-browser 会话，不读取用户正在使用的 Chrome Profile。
