# ShopSwarm 使用教程

ShopSwarm 是一个可以加载到 DSH 的购物研究插件。它让 DSH Agent 使用后台浏览器查找商品、查看规格和价格，并把结果交回 Agent。

## 1. 准备 DSH

安装 Node.js 24.21.0 和 pnpm 11.7.0。DSH 固定使用已验证的 `0.1.7-alpha.2`，不要安装 `latest`。本仓库的依赖和 lockfile 已固定该版本；源码启动入口使用本地依赖。如果需要全局 CLI，执行 `npm install -g @deepseek-ai/dsh@0.1.7-alpha.2`。上游来源为 [DSH 官方仓库](https://github.com/deepseek-ai/deepseek-harness)，不把参考源码复制进 ShopSwarm。

如果需要终端界面，再按所用 TUI 项目的说明安装 TUI。TUI 只是 DSH 的一个界面，不改变插件的调用方式。当前项目不把某个 TUI 当作运行时依赖。

## 2. 安装当前开发版

本次单工具流程为 0.3.0 开发版，尚未发布 Release。下面命令适用于包含本次修改的源码工作区。旧 Release v0.2.0 不提供新接口，不能用旧包验证新流程。

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm pack --pack-destination runtime/packages
pnpm run install:dsh -- headless /绝对路径/shopswarm-0.3.0.tgz
```

安装命令的路径替换为刚生成的 tarball 实际路径。把 headless 换成 web 可安装到 Web profile；本次只验证和更新 headless，Web 新接口未验证。安装后重新启动 DSH。源码修改后重新 build/pack/install；安装器更新 profile 依赖与 bundle，不修改 DSH 源码。

## 3. 配置与启动

DSH 主模型需要 DeepSeek 配置。默认 action=act 需要 JEV_API_KEY；action=open/observe/read 只观察、不调用 Jev，也不在插件内部调用报价提取模型。Jev 默认使用 https://api.tu-zi.com 的 jev-1.13。密钥放入本地 .env 或启动环境，不提交。

源码安装到 headless 后，从固定版本入口运行：

```bash
bash scripts/run-dsh.sh --profile headless --json "使用 ShopSwarm 查找德国两家商店的 Shure SM7B，核对商品与欧元报价并比价。只读，不购买。"
```

入口核对 Node.js 24.21.0、pnpm 11.7.0 和 DSH 0.1.7-alpha.2，加载 .env 并清除代理。headless 使用原生同步 Subagent；Lead 收到结果后再汇总。Web/TUI 调度不变。

## 4. 单工具流程

当前源码只注册shopswarm_browser。Lead先委派来源Subagent；静态事实用open/read或同会话CLI观察，需要交互才给act一个具体goal。默认四次决策预算，MORE_TARGETS自动翻页，实际执行一个动作后交回来源核对。返回sessionId、当前快照、URL/时间、ownerAgentId、逐步trace和cli连接。DONE不等于商品任务成功。当前优化状态见[优化记录](优化记录-2026-10-01-Jev效率.md)，收益只按实测声明。

页面交互先用 act，由 Jev 选择动作。只有当前交互的 act 失败、BLOCKED、预算耗尽或动作不受支持时，说明原因后才用 CLI fallback；恢复后后续交互仍先用 act。只读观察和已知 URL 导航可直接用 CLI，不以导航代替页面搜索、筛选或规格选择。返回 cli.executable + cli.args + 原生命令，以及 cli.env 中的 socket/config 路径用于同一浏览器；拿到连接参数本身不代表需要回退。去除继承代理，不另开 session 或连接用户 Chrome。CLI 操作后刷新 snapshot；再调用 act 时工具会刷新引用。action=open/observe/read 可不调用 Jev；完成用 action=close 释放插件槽位。

报告直接通过来源 Subagent 返回 Lead，无需 finish JSON 或逐字段引用校验。字段由问题决定。只查标价时，VAT 声明、库存、运费未知不导致整项失败；简短说明未确认即可。查到手价、交付或特定卖家时，相应条件不足才限制结论，不能声称满足。操作示例见[Skill](../skills/shopping-research/SKILL.md)。

ShopSwarm 加载时会向 DSH 注册包内 shopping-research Skill，Agent 可以通过 skill 工具加载，无需手工复制文件。工具说明和返回提示也要求交互先 act；这属于 Agent 调用约定，不是对 bash 的权限拦截。

默认四个同时来源，闲置十五分钟自动关闭。CLI 不更新插件租约，长调试需 observe。句柄绑定调用者，不能从 Lead 转给子 Agent。默认独立 headless，空配置，不读用户 Profile，不连接前台浏览器。

## 5. 边界与验证

执行层保留有效引用、所有权、超时、取消和清理。模型仍可能误读证据；核心配置和现金价格应有本次原文支持。只读，不购买、支付或绕过验证码及站点保护。站点阻断不承诺自动解决。

初版单工具67项检查与安装验证见[原验收](验证记录-2026-09-30-单工具浏览器.md)。当前Jev优化73项检查、类型与构建通过；真实五例4/5取得可核对标价，BIKE24被拒绝；iPhone的颜色/容量由Jev完成，但同名链接仍可能选错，导航超时仍需同会话恢复。详见[优化前后记录](优化记录-2026-10-01-Jev效率.md)。总耗时改善不等于Jev独立提速，强制每次act仍增加Jev Token。此前三工具记录不替代当前验收。X11焦点监测不完全覆盖Wayland。
