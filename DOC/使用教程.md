# ShopSwarm 使用教程

ShopSwarm 是一个可以加载到 DSH 的购物研究插件。它让 DSH Agent 使用后台浏览器查找商品、查看规格和价格，并把结果交回 Agent。

## 1. 准备 DSH

安装 Node.js 24.21.0 和 pnpm 11.7.0。然后从 [DSH 官方仓库](https://github.com/deepseek-ai/deepseek-harness)按当前发行版说明安装 DSH。不要把参考仓库源码复制进 ShopSwarm。

如果需要终端界面，再按所用 TUI 项目的说明安装 TUI。TUI 只是 DSH 的一个界面，不改变插件的调用方式。当前项目不把某个 TUI 当作运行时依赖。

## 2. 安装 ShopSwarm

公开发布后，直接在 DSH profile 中安装：

```bash
pnpm add shopswarm
```

开发版或还没有 npm 登录时，可以从本仓库打包安装：

在本仓库执行：

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm build
pnpm pack
```

把生成的 `shopswarm-*.tgz` 安装到 DSH 使用的 profile：

```bash
pnpm add /path/to/shopswarm-*.tgz
```

ShopSwarm 通过 Bundle patch 加入 DSH profile，不修改 DSH 源码。重新启动 DSH 后，Agent 就能看到 ShopSwarm 工具。

## 3. 配置密钥

`shopswarm_research` 需要：

```dotenv
JEV_API_KEY=你的 Jev 密钥
DEEPSEEK_API_KEY=你的 DeepSeek 密钥
```

把密钥放在 DSH profile 的环境配置中，不要提交到 Git。

## 4. 直接使用

在 DSH 或 TUI 中直接说清楚任务，例如：

> 查找两个来源的 2TB 移动固态硬盘，比较型号、容量、价格、运费和卖家。只读取页面，不购买。

Agent 会根据 Skill 判断是否需要多个来源。需要时，Lead Agent 可以派出多个 Subagent；每个 Subagent 负责一个来源，并使用 `shopswarm_research`。

## 5. 工具选择

- `shopswarm_research`：主要工具。让插件自动浏览一个来源，Jev 选择下一步页面动作，插件校验目标并调用 agent-browser 执行，最后检查报价证据。
- `shopswarm_browse`：只在 Jev 暂停并返回 `continuationId` 后使用。它在同一来源的浏览器会话中执行一批明确动作，不创建新会话，也不调用 Jev。
- `shopswarm_diagnose`：检查插件和浏览器是否能启动。

## 6. Jev 失败和 Subagent fallback

每个来源的一次研究持有一个浏览器会话。Jev 是默认动作选择器。只有 Jev 决策超时、返回无效动作、没有可用动作或反复无法推动页面时，当前来源 Subagent 才接管。`shopswarm_research` 会返回 `handoff.continuationId`；Subagent 把该 ID 和明确动作交给 `shopswarm_browse`，在同一标签页读取最新快照并继续操作。

当页面状态已恢复到 Jev 可继续操作时，Subagent 尽快调用 `shopswarm_research`，只传同一个 `continuationId`。Jev 会读取新的页面快照并继续原研究。Subagent 不自行宣布报价已核实。

浏览器超时、浏览器传输错误和输入处理错误不触发 Subagent fallback。登录、验证码、频控或来源无法继续时，把来源结果交回 Lead；Lead 可以请求用户处理、换来源或结束该来源。失败来源不能被伪造为成功，也不能用另一个来源的数据补齐。

## 7. Jev 和 Agent

Jev 只负责在当前页面的有效动作里选下一步，例如点击哪个按钮、选择哪个规格或向下滚动。Jev 与 Subagent fallback 都通过 ShopSwarm 的动作校验和 agent-browser 操作同一个后台会话。报价提取后，ShopSwarm 会在该会话中重新打开商品页核验；核验通过后才关闭会话并返回成功。

页面字段、报价和失败原因返回给调用它的 Agent。Agent 负责理解任务、决定是否派 Subagent、决定是否换来源，以及向用户说明结果。

## 8. 当前限制

插件只读页面，不购买、不支付、不绕过验证码。没有页面证据的价格、库存、优惠、运费和税费保持未知。真实站点是否可用取决于页面访问、登录状态和站点限制。

Subagent fallback 的浏览器会话默认在 5 分钟没有后续调用后关闭。`shopswarm_browse` 的动作批次没有固定的 8 步上限；每个浏览器命令仍有超时限制。
