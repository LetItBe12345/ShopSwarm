# 来源 Agent 主导：实现与真实验证

日期：2026-09-30。依据分支：`fix/shopping-evidence-and-jev-context`，未提交、未推送、未合并。核对时本地 main 与 origin/main 均为 `c4b166176d76a4efad1d5304993e1d5b0fd4ca3c`。本次为本地 0.3.0 开发版，旧 Release 不提供此接口。

## 已实现

来源 Subagent 从开始即负责浏览、商品与价格判断、歧义处理和报告。删除商品硬匹配、关键词打分、站点障碍词典、内部商品提取模型、隐藏文本模型与强制重开核对。Jev 改为可选单步，不要求先失败或恢复控制权。

保留会话所有权、有效引用、超时/取消/清理、结构检查与证据出处。原始页面可完整分段读取，不按关键词删减。报告区分 observed、inferred、unknown；摘录必须来自本会话保存快照，URL/时间/版本可引用工具元数据。reported 仅证明报告出处检查通过，不证明模型语义正确。

后台会话显式使用空配置、headed=false、auto-connect=false，不继承 Profile、登录态、CDP 或代理。资源忙时快速返回，可显式关闭。导航只等待新文档 DOM 就绪，不把正文为空当成执行失败。旧构建产物在 build 时清除，不再打包已删除模块。

## 发现的问题与回归

首轮 Samsung 将 URL/时间作为正文摘录提交，被拒绝后自行修正。现已支持 metadata 证据，不要求工具元数据出现在页面正文。最终分段 nextOffset 修复，最后一段不再回到旧游标。默认诊断去掉固定 Example Domain 标记，避免把页面差异误判为浏览器故障。

Samsung 回归从 14:06:42.897Z 开始，耗时 5分32.5秒。Agent 再次取得 1199 EUR，并以元数据引用 URL/时间完成报告；全部会话清理。期间有四次点击被遮挡、一次把不连续文本拼成单条 excerpt 被拒。Agent 自行恢复，不添加站点词典。Skill 已明确多段引用分别提交。回归快照包含 `ab11058a-4b01-421f-b467-490987e93791`，14:07:34.684Z。

本轮暴露的剩余边界：站点反机器人保护、控件遮挡和模型误读依然存在。官方域名可支持卖家推理，不能只因 URL 引用有效就认定页面直接观察到卖家；缺少明确文本的税费、库存或商品成色也不能擅自确定。

Aeron 中 Jev 实际调用一次，动作 CLICK，耗时 1508ms，请求 9670 bytes。默认 40 个候选按页面顺序分页，超过 100 个仍可访问。这个样本只证明实际 API 路径可用，不证明 Jev 提速，也不证明 40 优于 100；本轮未追加性能或公平比较。
