# ShopSwarm 设计说明

## 当前决策

2026-09-30 用户确认简化为一个工具：shopswarm_browser。DSH 管理 Lead 与来源 Subagent；Jev 为具体浏览子目标选择动作；adapter 校验当前引用并交 agent-browser CLI 执行。商品与报价判断由来源 Agent 完成，不另写调度器、提取模型或商品匹配规则。

前序三工具流程及十五次对比是历史状态，见[评估记录](评估记录-2026-09-30-修改后与直接浏览器.md)。当前单工具验证见[任务记录](../TODO/done/S6-单工具浏览器适配与任务验收.md)，67 项检查与真实 CLI 回归完成，见[验证](验证记录-2026-09-30-单工具浏览器.md)；未验证结果不当作支持承诺。

## 一个工具与同会话 fallback

Lead 先委派来源 Subagent，再由来源 Agent 调用 shopswarm_browser(startUrl, goal)。默认 act：打开独立 headless 会话，让 Jev 最多选择四步动作；maxSteps 可设 1–12，仅限制本次执行长度，不判断商品或任务完成。DONE、BLOCKED、错误、缺少输入、更多候选和预算耗尽均返回调用者，浏览器保持可继续状态。

工具同时提供 open（无 Jev 打开）、observe（刷新快照）、read（读取保存快照片段）和 close（清理）操作。没有额外 diagnose 或 browse 工具，也不要求 finish 报告。诊断属于开发脚本，最终答案通过 DSH 来源 Subagent 原生返回。

输出 sessionId、真实 ownerAgentId、snapshotId、页面 URL、采集时间、原始快照片段和 cli 连接信息。调用者使用 cli.executable、cli.args、cli.env 直接执行原生 agent-browser 命令，沿用同一 daemon 和页面，不重新打开 fallback 浏览器。连接信息只有会话与配置路径，不包含密钥或全部环境。

所有权只绑定实际调用者，不再用“subagent”角色误导转交。Lead 自建会话只能自己操作；应让来源 Agent 自己开始。默认最多四个并发来源，资源满立即说明调用者可恢复的会话。工具与 CLI 不并行操作同一会话。CLI 后再调用 Jev 会重新 snapshot，更新有效元素引用。

## Jev 上下文

复用现有 Jev 请求及 agent-browser adapter，不引入参考项目的完整框架。Jev 只从当前有效动作和引用中选择；输入值由来源 Agent 明确提供，不调用隐藏文本模型。默认四十个候选按页面顺序分页，targetOffset/pageOffset 可选下一段，不进行关键词排名。四十不是已证明最优值。

每次动作后刷新页面。Jev DONE 只表示它认为浏览步骤结束；最终能否回答用户由来源 Agent 读取证据判断。没有置信度阈值、商品字符串匹配、页面关键词拦截或字段 completeness gate。

## 任务决定验收

标价查询通常需要目标商品、明确要求的规格、当前购买标价和币种，以及来源与采集时间。月供、UVP、trade-in 与附条件优惠必须区分。这里是 Agent 回答任务所需的事实，不是代码硬编码字段表。

库存、VAT 明确声明、运费或法律卖家名称不属于所有问题的固定必达条件。未要求且缺失时保留未知，仍可回答已查到标价。用户问到手价时税费、运费与优惠条件才影响结论；问交付、卖家、新品时相应信息才成为核心要求。缺项给出已知结果和具体限制，不把整个任务一概失败。

可比较明确的标价并注明运费未计；不能据此声称最终到手价最低。商品或配置不同不能混排，缺少条件不能虚构。原始观察可溯源，引用与推理由 Agent 说明；不再通过逐字段完全一致原文验证器阻塞报告提交。模型仍可能误读证据，Lead 应复核核心报价与配置。

## 必要执行约束

保留参数结构、HTTP(S) 导航、当前引用、调用者所有权、取消、超时与资源清理。导航只等待新文档 DOM 就绪，不按正文关键词判断成功。执行失败保留事实与可读观察，不推断商品不符合要求。页面资料不是工具授权；不购买、支付或绕过站点保护。

默认 --headed false、--auto-connect false、空配置，去除继承代理、Profile、状态和 CDP。会话 socket/config 放在当前工作目录 runtime/shopswarm-browser，便于 DSH bash sandbox 沿用；这里是私有运行数据，不入包或 Git。默认闲置十五分钟自动清理；每次工具调用更新租约，直接 CLI 不更新插件租约，长调试需 observe。取消和插件卸载清理来源，正常完成调用 close。原始 Chrome Profile 复用仍未开放为产品配置。
