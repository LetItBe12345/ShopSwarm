## 已实现功能

一个来源的一次研究持有一个后台浏览器会话。Jev 默认选择页面动作；只有 Jev 超时、返回无效动作或页面没有进展时，才返回 `continuationId` 给当前来源 Subagent。Subagent 用 `shopswarm_browse` 在同一会话执行明确动作，页面恢复后用同一个 ID 调用 `shopswarm_research`，把会话交回 Jev。

动作批次没有固定 8 步上限。浏览器传输错误、登录、验证码、限流和无法核验的结果不会伪装成成功。

## DSH 安装修复

问题出在安装后的 profile，不是远程 Git 仓库的源码：部分 DSH CLI 版本执行 `plugin add` 后只更新 `dependencies`，没有把带有 `dsh.bundle` 声明的包加入 `dsh.profile.bundles`。新 profile 还可能因为 pnpm 的构建脚本安全策略拒绝 `agent-browser` 的 postinstall。

现在使用仓库提供的安装入口：

```bash
pnpm run install:dsh -- headless /绝对路径/shopswarm-0.2.0.tgz
```

入口位于 `scripts/install-dsh-plugin.ts`，会：

1. 初始化目标 DSH profile。
2. 在 profile 的 `pnpm-workspace.yaml` 中允许 `agent-browser: true`。
3. 调用 DSH `plugin add` 安装包。
4. 扫描已安装依赖的 `dsh.bundle` 声明。
5. 把缺失的 bundle 名称补进 `dsh.profile.bundles`。

安装后可以检查：

```bash
dsh --profile headless --dump-config | rg 'shopswarm'
```

## 真实购物研究边界

曾用真实 DSH/ShopSwarm 运行时访问 Apple 官方页面：

`https://www.apple.com/shop/buy-iphone/iphone-16`

页面读到了 iPhone 16、Apple、USD 799 广告价；页面产品数据还包含 USD 829 的整机价。ShopSwarm 没有返回完整的 `status: success`，原因是容量选项在后台会话中显示为 disabled，Jev 多次无法推动页面，最终返回 `no_progress` 和 `continuationId`。

已验证过同一 `continuationId` 的流程：

1. `shopswarm_research` 返回 Subagent handoff。
2. `shopswarm_browse` 在原浏览器会话执行颜色选择。
3. 再用同一个 ID 调用 `shopswarm_research`，交回 Jev。

这证明了会话恢复协议，但不代表 Apple 这个页面的完整报价已经成功核验。容量、优惠条件、税费和运费不能写成已确认。

## Herdr 中继续测试

当前外部 Codex 进程没有 `HERDR_ENV=1`，不能从这里控制 Herdr。下一位在 Herdr 管理的 pane 中继续时，先确认：

```bash
test "$HERDR_ENV" = 1
```

然后在当前 tab 新开右侧 pane，保留当前目录：

```bash
herdr pane split --current --direction right --cwd "$PWD" --no-focus
```

从返回的 JSON 读取新 pane ID，再在新 pane 运行真实 CLI。建议先打包当前代码并安装到隔离 profile：

```bash
export PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"
corepack prepare pnpm@11.7.0 --activate
pnpm build
pnpm pack --pack-destination /tmp
```

启动命令必须清除代理变量，并把真实密钥放在当前 DSH 进程可读的环境中：

```bash
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u FTP_PROXY -u NO_PROXY \
  -u http_proxy -u https_proxy -u all_proxy -u ftp_proxy -u no_proxy \
  -u AGENT_BROWSER_PROXY -u AGENT_BROWSER_PROXY_BYPASS \
  node --env-file-if-exists=.env \
  node_modules/@deepseek-ai/dsh/lib/bin.js \
  --profile headless --json \
  '请研究一个真实公开商品页面。只读取页面，不购买；如果 shopswarm_research 返回 continuationId，使用 shopswarm_browse 在同一会话恢复，然后用同一个 ID 交回 Jev。'
```

用 Herdr 的 `pane wait-output` 等待明确的 `tool_call`、`tool_result`、`final` 或 `exit` 输出；不要在两分钟时提前停止。结束后读取 `recent-unwrapped` 输出，记录来源 URL、采集时间、成功或失败、耗时、是否后台运行和是否发生焦点变化。

## 不要误报

- CI 通过不等于真实 Jev 购物研究成功。
- `shopswarm_browse` 返回 `status: ok` 只表示动作批次执行，不表示报价已核验。
- Jev 返回 `DONE` 不代表任务成功，必须看 ShopSwarm 的证据校验结果。
- 不要把 USD 799 广告价和 USD 829 整机价混成一个无条件价格。
- 不要提交 `.env`、Cookie、浏览器 Profile、运行日志或 `/runtime/` 临时数据。
