# 单工具浏览器 adapter 验证

## 当前实现

工作分支 fix/shopping-evidence-and-jev-context，基于与 origin/main 同步的 c4b166176d76a4efad1d5304993e1d5b0fd4ca3c。前序未提交重构与本次单工具改动在同一尚未合并分支完成。当前只注册 shopswarm_browser；旧 diagnose、browse、research 入口删除，不保留工具别名。旧 Release 0.2.0 不提供该接口，0.3.0 尚未创建 Tag 或 Release。

Jev 选择当前有效动作，agent-browser 执行；来源 Agent 可直接用返回的 session/CLI/socket/config 继续操作原浏览器。不提交 finish JSON，不逐字段匹配报告原文，不设置固定字段齐全关卡。用户问题决定核心要求：查标价时税费细项、库存等未知不把整体判失败；查到手价等仍需相关条件。

实际所有者为调用工具的 Agent，不假定调用者一定是 Subagent。Lead 先委派来源，再由来源开始。默认四个同时来源、十五分钟闲置租约，显式 close、取消和插件卸载释放。CLI 操作不更新插件租约，长调试需 observe。当前不新增 Chrome Profile 功能。

来源 [Apple 德国购买页](https://www.apple.com/de/shop/buy-iphone/iphone-17/6,3%22-display-256gb-schwarz)。首次采集 2026-09-30T18:37:23Z；修复回归工具观察为 18:40:28.597Z，后续同会话 CLI 读取已选 Black/256GB 与精确 1.099,00 €。现金标价与 45,79 €/月、Trade In 区分。原始页面和 DOM 选择证据在根/子 JSONL 中；采集时间按工具或 CLI 实际观测记录，不把任意概览价格等同精确配置。

最终包从基础购买页的当前 DOM 读到 `256 GB` / `Schwarz` / `1.099,00 €` 配置列表，实际 CLI 返回 source=active-tab-html、truncated=false，时间 18:52:59.329Z；工具此前快照时间为 18:52:36.700Z。没有强制进入配置 URL 或结账，明确报价对应关系即可。

附加税费、库存、交付或法律卖家未知不阻塞本次标价回答。unknown 表示本轮未核对，不能笼统断言网站不存在相应信息。但最终模型“有货型配置”措辞不严谨：配置存在不能证明有库存。Lead 搜索新闻补充核验只作旁证，不计作本轮浏览器报价，也不据搜索摘要证明涨价历史。

## 根据失败修正

1. open 只要求 URL；具体 Jev goal 仅 act 必需，避免给纯观察增加要求。补一项回归，确保无 goal 不调用 Jev且返回可继续会话。
2. 说明 CLI close 与插件租约不同，要求最后工具 close 并确认 closed。修复后的真实任务已按此释放。
3. BrowserExecutionError 保留复查失败的原始浏览器原因；页面 URL/ref 改变与服务请求错误分开。Jev 已成功返回后的浏览器错误不再伪装 jev_error，也不抹掉已返回的 Jev 用量。对应失败回归通过；没有声称因此解决 Cloudflare。
4. Jev 始终收到只读、禁止购买/支付/绕过保护的任务约束，不使用商品关键词或控件名字黑名单来判断语义。

Jev 目前仍可能返回 MORE_TARGETS，需要继续给 targetOffset 或直接 CLI。已记录样本主要验证 API 与 fallback，不能宣称 Jev 更快，不能证明四十个候选是最优，也没有新增性能比较。

## 后台、焦点、日志与边界

独立 headless，headed=false、auto-connect=false，socket/config 在私有 runtime/shopswarm-browser；工具与 CLI 去除继承代理、Profile、CDP 等。没有连接用户 Chrome。真实回归与双来源结束时默认及该 runtime 目录 session 列表均为空。X11 焦点记录无变化、值一直 0x0；不宣称覆盖全部 Wayland 行为。本轮不读取原始用户 Profile。

私有原始记录：

- runtime/single-tool-acceptance-1790793352954/：安装与首次 CLI。
- runtime/single-tool-regression/：参数修复回归。
- runtime/single-tool-price-comparison/：两个来源及受阻证据。
- runtime/single-tool-final-live/：最终包回归。

每次包含 prompt、cli.log、恢复的根/子 JSONL、工具调用与返回、usage、URL/时间与焦点/清理元数据。根/子日志完整恢复，现场过程不介入。运行目录已忽略，已知密钥脱敏，不提交日志、Cookie 或 Profile。任务结果经人工审阅，不根据 exit=0 自动判断。

当前使用：先从源码 pnpm check / pnpm pack，再 pnpm install:dsh -- headless /绝对路径/shopswarm-0.3.0.tgz；从仓库运行 bash scripts/run-dsh.sh --profile headless --json "用 ShopSwarm 查询德国某商品当前标价并给来源"。最终工具接口见[教程](使用教程.md)、[Skill](../skills/shopping-research/SKILL.md)。安装脚本与 runner 依赖已配置的 DSH，站点风控、模型误读及所有登录场景仍有边界。
